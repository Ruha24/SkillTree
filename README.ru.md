# SkillTree

[English](README.md) · **Русский**

![Экран дерева навыков](docs/skilltree.png)

Деревья навыков для Paper/Folia на экране из display-сущностей: свободный курсор от мыши, пан, зум, вкладки,
подсказки и анимации. **Без модов и без ресурспака** — всё рисуется ванильными `text_display` и `item_display`.
Работает на движке экранов ScreenUI — его jar лежит в каждом релизе SkillTree.

## Возможности

- несколько деревьев — вкладки экрана, у каждого свои очки, изученное и сброс;
- узлы с рангами, скрытые узлы, сходящиеся ветки (любой или все родители), требования по уровню и правам;
- эффекты узлов: атрибуты, права, разовые команды от консоли;
- очки за уровни опыта, бонусные очки командой, сброс навыков игроком за уровни;
- иконки — ванильные предметы, предметы Nexo или модели из ресурспака;
- английский и русский языки, все тексты с разметкой MiniMessage;
- плейсхолдеры PlaceholderAPI;
- подсветка узлов, которые можно изучить, кнопка «к центру».

## Требования

- Paper или Folia 26.x, Java 25.
- ScreenUI — движок экранов, `ScreenUI-<версия>.jar` в [релизе SkillTree](https://github.com/Ruha24/SkillTree/releases).
- Необязательно: [PlaceholderAPI](https://modrinth.com/plugin/placeholderapi) — плейсхолдеры,
  [Nexo](https://nexomc.com) — иконки из предметов Nexo.

## Установка

1. Положить `ScreenUI-<версия>.jar` и `SkillTree-<версия>.jar` из [релиза](https://github.com/Ruha24/SkillTree/releases) в `plugins/`
   и перезапустить сервер.
2. Выбрать язык в `plugins/ScreenUI/config.yml` (`language: en` или `ru`) — он общий для обоих плагинов.
3. Настроить деревья в `plugins/SkillTree/trees/*.yml` (по умолчанию два примера: `main` и `gathering`).
4. Применить правки: `/skilltree reload`.
5. По желанию — ресурспак `ScreenUI-shaders.zip`: экраны нужного размера при любом FOV без калибровки
   (см. [FOV](#fov)).

Обновление с SkillTree 1.0.0 (когда это был один плагин CameraUI): удалить старый `CameraUI-1.0.0.jar` и положить
оба новых. Настройки сами переедут в `plugins/ScreenUI`, деревья и тексты — из `plugins/CameraUI` в
`plugins/SkillTree`; прогресс игроков и FOV останутся. Права стали
`skilltree.use` / `skilltree.admin`, плейсхолдеры — `%skilltree_…%`.

## FOV

Размер экрана зависит от FOV игрока, а его сервер не знает. ScreenUI совмещает два способа:

- **Шейдерный пак** `ScreenUI-shaders.zip` (в релизе) — его шейдеры каждый кадр рисуют экраны так, будто FOV
  ровно 70. Добавить его в ресурспак сервера (с Nexo — в `plugins/Nexo/pack/external_packs/` и
  `generate_gif_shaders: false` в `settings.yml` Nexo) и выставить `shader-pack: true` в
  `plugins/ScreenUI/config.yml`: игрокам, у которых загрузился пак сервера, больше ничего не нужно.
- **Калибровка** — перед первым экраном (у кого нет пака), командой `/screenui fov` или кнопкой «FOV»: игрок
  поднимает золотую линию к верхнему краю экрана (FOV), потом ведёт к правому (соотношение сторон). С работающими
  шейдерами она намеряет ровно 70, так что способы не спорят.

Шейдеры не покрывают: шейдерпаки Iris/OptiFine (такие игроки калибруются), иконки-блоки и предметы со своей моделью
(щит, сундук, головы) — для иконок лучше плоские предметы. Вкладки и кнопки остаются у краёв на любом мониторе —
16:9, 21:9, 16:10.

## Управление

| Действие | Что делает |
|---|---|
| Мышь | Двигает курсор |
| ЛКМ по узлу | Изучить узел (следующий ранг) |
| ЛКМ по пустому месту | Взять / отпустить дерево — перетаскивание |
| Колесо | Зум вокруг курсора |
| ЛКМ по вкладке | Переключить дерево |
| «СБРОС НАВЫКОВ» | Сбросить дерево за уровни опыта (подтверждение вторым нажатием за 3 с) |
| «К ЦЕНТРУ» | Вернуть дерево в исходное положение |
| «FOV … · изменить» | Калибровка |
| Shift | Выйти |

## Команды и права

| Команда | Право | Что делает |
|---|---|---|
| `/skilltree [дерево]` | `skilltree.use` (все) | Открыть / закрыть экран, сразу на вкладке дерева |
| `/screenui fov` | — | Калибровка (то же: `/skilltree fov`) |
| `/screenui fov <30-110>` \| `reset` | — | Указать свой FOV числом / сбросить калибровку |
| `/screenui reload` | `screenui.admin` (op) | Перечитать `config.yml` и тексты ScreenUI |
| `/skilltree reload` | `skilltree.admin` (op) | Перечитать тексты и `trees/*.yml` SkillTree |
| `/skilltree reset <ник> [дерево]` | `skilltree.admin` | Сбросить изученное в дереве (без дерева — во всех). Очки возвращаются, разовые команды узлов — нет |
| `/skilltree points <ник> [дерево]` | `skilltree.admin` | Сколько очков потрачено и откуда они: базовые, за уровни, бонусные |
| `/skilltree points <ник> <дерево> add\|take\|set <n>` | `skilltree.admin` | Бонусные очки дерева — например, награда из квестов. Открытый экран обновляется сразу |
| `/skilltree learn <ник> <дерево> <узел>` | `skilltree.admin` | Выдать следующий ранг узла в обход родителей, уровня и права. Очки тратятся как обычно, команды узла выполняются |
| `/skilltree unlearn <ник> <дерево> <узел>` | `skilltree.admin` | Забрать ранг узла. Забытый совсем узел уносит потомков, которым он был нужен; очки возвращаются |

Команды администратора работают из консоли (удобно вызывать из других плагинов), с автодополнением,
только для игроков в сети.

## Настройка

### `plugins/ScreenUI/config.yml`

| Ключ | По умолчанию | Что |
|---|---|---|
| `language` | `en` | Язык текстов ScreenUI и плагинов на нём: `en`, `ru` |
| `sensitivity` | `0.028` | Скорость курсора: единиц экрана за 1° поворота мыши |
| `fov` | `70` | FOV, под который строятся экраны, если игрок не калибровался |
| `shader-pack` | `false` | `true` — `ScreenUI-shaders.zip` есть в паке сервера |
| `hud-mode` | `spectator` | Как спрятать HUD на время экрана: `spectator` (без полоски опыта и прицела), `creative` (без полоски опыта), `none` |
| `protection.combat-seconds` | `10` | Сколько секунд после урона нельзя открыть экран |

### Деревья — `plugins/SkillTree/trees/<id>.yml`

Каждый файл — отдельная вкладка; id дерева — имя файла. Полное описание всех полей — в комментариях
`trees/main.yml`. Коротко:

```yaml
tab: "ОСНОВЫ"           # подпись вкладки
order: 1                # порядок вкладок (меньше — выше)
title: "ДРЕВО НАВЫКОВ"  # заголовок экрана
points: 3               # очков у каждого игрока изначально

level-points:           # очки за уровни опыта (по максимальному достигнутому уровню)
  enabled: true
  every: 5              # amount очков за каждые every уровней — или свои пороги milestones
  amount: 1
  max: 15               # потолок (0 — без потолка)

respec:                 # сброс игроком: levels + per-point за каждое потраченное очко
  enabled: true
  levels: 5
  per-point: 1

nodes:
  core: { x: 0, y: 0, icon: nether_star, name: "Ядро" }   # без parent — стартовый
  a1:
    x: 0                # клетка сетки, y вверх
    y: 1
    icon: amethyst_shard          # ванильный предмет или nexo:<id>; лучше плоские предметы
    # icon-model: ns:путь         # модель из ресурспака поверх иконки
    name: "<light_purple>Кристалл"
    description: "+1 к удаче"
    parent: core                  # или список: [a1, s1] — хватит любого
    # parent-mode: all            # со списком: нужны все родители
    cost: 1
    ranks: 2                      # сколько раз можно изучить
    # min-level: 10
    # permission: vip.skills
    # permission-text: "только для VIP"
    # hidden: true                # «?», пока не изучен ни один родитель
    effects:
      attributes: { luck: 1 }     # за ранг; можно процентом: movement_speed: 10%
      # permissions: [ "someplugin.feature" ]
      # commands: [ "xp add {player} 5 levels" ]   # один раз за каждый ранг

labels:                 # подписи веток на поле
  - { x: 0, y: 3.55, text: "АРКАНА" }
```

Если в файле ошибки, все они пишутся в консоль, а в игре остаётся прежняя версия этого дерева.

### Тексты — `messages_<язык>.yml`

`plugins/SkillTree/messages_<язык>.yml`: экран дерева, подсказки, панель подробностей, чат, ответы команд,
ошибки конфига. Разметка MiniMessage (`<red>`, `<#e8b84a>`), подстановки `{имя}` описаны у каждой
строки. Ключи, которых нет в файле (добавились в обновлении), берутся из jar.

Свой язык: `language: de` в `plugins/ScreenUI/config.yml` — плагин создаст `messages_de.yml` копией английского,
его остаётся перевести.
Стандартные деревья создаются на языке сервера только при первом запуске, когда папка `trees/` пустая.

## Очки и эффекты

- **Очки игрока в дереве** = `points` из конфига + очки за уровни + бонусные (выданные командой).
- **Очки за уровни** считаются по максимальному уровню, которого игрок достигал, — смерть, зачарование и
  сброс их не отнимают. Начисляются при смене уровня и при входе, с сообщением в чат.
- **Атрибуты и права** действуют, пока узел изучен, и пересчитываются при входе, возрождении, изучении,
  сбросе и `/skilltree reload`. Модификаторы атрибутов с ключами `cameraui:skill/…` сохраняются в файле игрока;
  если удалить плагин, снять их можно `/attribute … modifier remove`.
- **Команды** выполняются от консоли один раз — при первом получении ранга. После сброса и повторного изучения
  награда не выдаётся снова.
- Данные хранятся в PDC игрока (его файл в мире) — отдельная база не нужна. Если убрать узел из конфига,
  его id у игроков остаётся: вернёте узел — вернётся и навык.

## Плейсхолдеры

Нужен PlaceholderAPI. Про конкретное дерево — `%skilltree_<дерево>_points_free%`, без дерева — про первое по
порядку вкладок.

| Плейсхолдер | Значение |
|---|---|
| `%skilltree_points_total%` / `_spent` / `_free` | Очков всего / потрачено / свободно |
| `%skilltree_points_base%` / `_level` / `_bonus` | Откуда очки: из конфига / за уровни / выданные командой |
| `%skilltree_max_level%` | Максимальный достигнутый уровень опыта |
| `%skilltree_next_point_level%` | На каком уровне следующее очко (пусто — больше не будет) |
| `%skilltree_learned%` / `%skilltree_nodes%` | Изучено узлов / всего узлов (без стартовых) |
| `%skilltree_learned_<id>%` | Изучен ли узел (хотя бы ранг 1): `true` / `false` |
| `%skilltree_rank_<id>%` | Изученный ранг узла (0 — не изучен) |
| `%skilltree_respec_cost%` | Цена сброса в уровнях (пусто — сброс выключен) |


## Ограничения

- Курсор отстаёт на пинг.
- Шрифт ванильный пиксельный; гладкий — только через TTF в ресурспаке.
- Экраны рассчитаны на вид от первого лица. В F5 они мельче — камера отъезжает назад, а переключить игроку вид
  сервер не может.
- Прицел прячется только при `hud-mode: spectator`.
- Камера и экран висят на 64 блока выше потолка мира. Если в `paper-world-defaults.yml` включён
  `entities.tracking-range-y`, экран может не прийти клиенту.

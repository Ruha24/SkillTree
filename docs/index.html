SkillTree — деревья навыков

Экран навыков прямо в мире: без модов и без обязательного ресурспака. Игрок открывает /skilltree, двигает мышью курсор, изучает узлы, а навыки дают атрибуты, права и награды.

Установка

  • Положите ScreenUI-1.0.0.jar (движок экранов) и SkillTree-1.1.0.jar в plugins/ и перезапустите сервер.
  • Язык выбирается в plugins/ScreenUI/config.yml (language: ru). SkillTree создаст в plugins/SkillTree/ тексты и папку trees/ с двумя готовыми деревьями: main и gathering.
  • Откройте экран командой /skilltree. Право на неё по умолчанию есть у всех.

PlaceholderAPI и Nexo необязательны. С PlaceholderAPI появятся плейсхолдеры %skilltree_…%, с Nexo — иконки узлов из его предметов.

Управление на экране

Пока экран открыт, игрок сидит на месте, а камера смотрит на экран. Поворот мыши двигает курсор-стрелку.

ЛКМ по узлуизучить узел или его следующий ранг
ЛКМ по пустому местувзять дерево и тащить, второй клик — отпустить
Колесо мышиприблизить или отдалить вокруг курсора
ЛКМ по вкладкепереключить дерево
«Сброс навыков» ×2сбросить дерево за уровни опыта, второе нажатие подтверждает
Shiftзакрыть экран

При наведении на узел справа появляется панель: описание, цена, требования и что даёт узел в цифрах.

· после «Ядро»
· уровень 15 (ваш макс. 12)
· свободно очков: 3

Когда экран не открывается

Пока экран открыт, игрок беззащитен в мире. Поэтому экран не открывается в бою (10 секунд после урона), в воде и лаве, в огне, в полёте и на транспорте. Любой урон закрывает экран.

Команды и права

КомандаЧто делает
/skilltreeОткрыть или закрыть экран.
/skilltree <дерево>Открыть сразу на вкладке дерева, например /skilltree gathering.
/skilltree fovКалибровка под свой FOV: поднять золотую линию к краю экрана и кликнуть. То же — кнопка «FOV · изменить» на экране.
/skilltree fov <30-110>Указать свой FOV из настроек Minecraft числом. /skilltree fov сброс вернёт значение по умолчанию.

Для администраторов

Работают и из консоли, поэтому их можно вызывать из других плагинов: квестов, наград, доната. Действуют только на игроков в сети.

КомандаЧто делает
/skilltree reloadПеречитать config.yml, messages.yml и все деревья.
/skilltree reset <ник> [дерево]Сбросить изученное в дереве, без дерева — во всех. Очки возвращаются.
/skilltree points <ник> [дерево]Показать очки: потрачено, всего, откуда взялись.
/skilltree points <ник> <дерево> add|take|set <n>Выдать, забрать или задать бонусные очки дерева. Открытый экран обновится сразу.
/skilltree learn <ник> <дерево> <узел>Выдать следующий ранг узла без проверки родителей, уровня и права. Очки тратятся как обычно.
/skilltree unlearn <ник> <дерево> <узел>Забрать ранг узла. Если узел забыт совсем, забываются и потомки, которым он был нужен.
ПравоПо умолчаниюДаёт
skilltree.useвсеОткрывать экран дерева. Свой FOV (/screenui fov) может менять каждый.
skilltree.adminоператорыreload, reset, points, learn, unlearn.

Деревья

Каждый файл plugins/SkillTree/trees/<id>.yml — отдельное дерево и вкладка на экране. Id дерева — имя файла. У каждого дерева свои очки, изученное и сброс. Если дерево одно, вкладок на экране нет.

tab: "РЕМЕСЛО"          # подпись вкладки
order: 2                # место вкладки: меньше — выше
title: "РЕМЕСЛО"        # заголовок экрана
points: 2               # очки у каждого игрока изначально

level-points:           # очки за уровни опыта
  every: 10              # 1 очко каждые 10 уровней
  amount: 1
  max: 8                 # не больше 8 за уровни

respec:                 # сброс самим игроком
  levels: 3              # цена: 3 уровня…
  per-point: 1           # …+1 за каждое потраченное очко

nodes:
  core: { x: 0, y: 0, icon: wooden_pickaxe, name: "Подмастерье" }
  d1:
    x: 1
    y: 0
    icon: iron_pickaxe
    name: "Шахтёр"
    description: "+10% к скорости добычи"
    parent: core
    ranks: 3
    effects:
      attributes: { block_break_speed: 10% }

labels:
  - { x: 3, y: -0.55, text: "ДОБЫЧА" }

После правки — /skilltree reload. Если в файле ошибка, все ошибки с номерами узлов выводятся в консоль, а в игре остаётся прежняя версия этого дерева.

Узлы

ПолеЧто задаёт
x, yКлетка сетки: 0,0 — центр, x вправо, y вверх. Два узла в одной клетке нельзя.
iconВанильный предмет (diamond_sword) или предмет Nexo (nexo:fire_orb).
icon-modelМодель из ресурспака поверх иконки: namespace:путь. Работает без Nexo.
name, descriptionНазвание и описание для подсказки. Можно цвета MiniMessage: "<gold>Палач</gold>".
parentУзел, который нужно изучить раньше. Можно список [a1, s1] — тогда хватит любого. Без parent узел стартовый и изучен сразу.
parent-modeall — нужны все родители из списка (узел на стыке веток). По умолчанию any — любой.
costЦена в очках, по умолчанию 1. У узла с рангами — за каждый ранг.
ranksСколько раз узел можно изучить. Атрибуты умножаются на ранг, на узле видна плашка «2/3».
min-levelС какого уровня опыта открывается.
permissionПраво, без которого узел закрыт, например для VIP. Текст в подсказке — permission-text.
hiddentrue — узел показан «?» без иконки и названия, пока не изучен его родитель.

Что даёт узел — effects

effects:
  attributes:            # пока узел изучен; число или процент, за один ранг
    max_health: 2          # +1 сердце
    movement_speed: 5%
  permissions:           # права, пока узел изучен
    - someplugin.feature
  commands:              # от консоли, один раз — при первом изучении ранга
    - "give {player} diamond 3"

Названия атрибутов — как в команде /attribute: max_health, armor, attack_damage, movement_speed, luck, block_break_speed, oxygen_bonus, step_height и другие. В командах можно подставить {player}, {uuid}, {node}, {rank}, {tree}.

Команды выполняются только при первом получении ранга. Если игрок сбросит навыки и изучит узел заново, награда не выдастся второй раз.

Очки и сброс

Очки игрока в дереве складываются из трёх частей:

  • Базовые — points из файла дерева.
  • За уровни опыта — level-points: равномерно (every, amount) или своими порогами milestones: { 5: 1, 10: 1, 20: 2 }, с потолком max. Считаются по максимальному уровню, которого игрок достигал, поэтому смерть и зачарование их не отнимают.
  • Бонусные — выданные командой /skilltree points.

Игрок может сам сбросить дерево кнопкой «Сброс навыков» на экране, если в файле есть секция respec. Цена — уровни опыта: levels плюс per-point за каждое потраченное очко. Все очки возвращаются.

Тексты — messages.yml

Все тексты экрана, подсказок, панели подробностей, сообщений в чат и ответов команд лежат в messages.yml. Можно перевести плагин на другой язык или поменять формулировки.

  • Цвета — разметка MiniMessage: <red>, <#e8b84a>, <gradient:…>.
  • Подстановки — {имя}. Какие доступны, написано в комментарии у каждой строки.
  • Формы слов для чисел — списком: points: [очко, очка, очков]. Для английского достаточно двух форм.
  • Если ключа нет в файле, например после обновления, берётся текст по умолчанию.

Плейсхолдеры PlaceholderAPI

Про конкретное дерево — %skilltree_<дерево>_points_free%. Без дерева — про первое по порядку вкладок.

ПлейсхолдерЗначение
%skilltree_points_free%Свободные очки. Также _points_total и _points_spent.
%skilltree_points_level%Очки за уровни. Также _points_base и _points_bonus.
%skilltree_max_level%Максимальный достигнутый уровень опыта.
%skilltree_next_point_level%На каком уровне придёт следующее очко.
%skilltree_learned%Сколько узлов изучено. %skilltree_nodes% — сколько всего.
%skilltree_learned_<узел>%Изучен ли узел: true или false.
%skilltree_rank_<узел>%Изученный ранг узла.
%skilltree_respec_cost%Цена сброса в уровнях.

Плейсхолдеры работают для игроков в сети. Для остальных возвращается пустая строка.

Ограничения

  • FOV. Клиент не сообщает серверу свой FOV. Экран строится под FOV 70, игрок с другим FOV настраивает свой калибровкой (/skilltree fov или кнопка на экране). При первом открытии калибровка запускается сама.
  • Вид от третьего лица (F5). Экран выглядит мельче: камера отъезжает назад, а переключить игроку вид сервер не может.
  • Пинг. Курсор движется с задержкой, равной пингу игрока.
  • Экран над миром. Он висит на 64 блока выше потолка мира. Если в paper-world-defaults.yml включён entities.tracking-range-y, экран может не дойти до клиента.
  • Узкие мониторы. Экран рассчитан на 16:9. На 4:3 вкладки и кнопку сброса по краям может обрезать.

Изученные навыки, очки и свой FOV хранятся в данных игрока на сервере, отдельная база не нужна.
